# UI labels

All user-visible occurrences of the product name were redirected from `UniMote` to `TV пульт`.

Affected resources include the shared `app_name` resource and localized product-name rating/feedback strings. The explicit DEX product-name strings were also redirected.

Technical identifiers were intentionally left unchanged because they are not display labels: `Theme_UniMote`, `Theme_UniMote_AdAttribution`, `UniMote.Network`, `UniMoteSDK`, and `unimote-*` identifiers.

No new author/developer UI field was added. The APK did not contain a separate user-visible signature field to replace.
